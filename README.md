## 图标规格

- 格式：SVG
- 尺寸：160 × 160
- 配色：遵循 BSP 设计规范色彩体系

## 设备多状态图标

支持开/关、运行中等多种状态的设备图标：灯光、空调、新风、地暖、除湿机、消毒机、窗帘、推窗、纱窗、蚊帐、智能开关等。

## 设备单状态图标

仅展示设备默认状态：空调伴侣、网关、红外遥控器、门锁、摄像头、各类传感器（温湿度、光照、人体存在、气味、雨量等）、排气扇、阀门、断路器、语音面板、数码相框等。

## UI 图标

- **操作类**：首页、设备、通知、关于、帮助、固件更新、延时、连接、场景触发、窗户/百叶操作等
- **状态类**：定位、展开、禁用、上一曲、暂停
- **场景类**：默认、阅读、音乐、电影、娱乐
- **环境类**：TVOC、氨气、H2S
- **插画类**：无设备/场景/日志/成员/家庭/消息/搜索结果、蓝牙、NFC 引导、定位

## 使用说明

所有图标可直接用于微信小程序、Web 或移动端项目开发。
